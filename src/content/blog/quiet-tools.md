我喜欢打开就能开始工作的工具。界面清楚、反馈及时，然后退到一边。

## 简单的标准

- 能否轻松带走自己的内容？
- 离线时还能做多少事？
- 它是否帮助我完成原本要做的事？

例如，一份普通的 Markdown 文件，可以在很多地方继续编辑：

```md
# 今天的想法

先写下问题，再寻找答案。
```

工具会变化，自己留下的文字可以更长久。

# Proposal

## Why

当前项目只有 OpenSpec 配置，还没有可发布的个人网站。需要一个以文章阅读和个人介绍为核心的博客，让访客能快速了解作者、浏览内容并找到感兴趣的文章；视觉体验参考 Joye Blog，但使用独立的品牌、文案与素材。

## What Changes

- 新建中文优先、适配桌面和移动端的个人博客首页，展示作者简介、精选或近期文章，以及通往完整内容的入口。
- 提供文章列表、标签筛选、分页和文章详情，支持以 Markdown/MDX 文件维护内容，并清楚展示标题、日期、摘要和正文。
- 提供独立的关于页面，集中展示个人介绍、经历和可配置的外部链接。
- 提供笔记列表与详情，以简短的 Markdown/MDX 内容持续记录想法。
- 提供站内文章搜索，支持关键词查询、结果展示和无结果状态。
- 提供浅色、深色和跟随系统三种主题模式，记住访客的选择。
- 建立基础的可访问性、页面元信息、站点地图和 RSS 输出，使网站可阅读、可分享、可订阅。

第一版以静态内容和静态部署为目标。演讲、项目、友链、联系表单、评论、访问统计和参考站的角色动画不在本次范围内；若需展示联系方式，使用作者配置的外部链接。

## Capabilities

### New Capabilities

- `personal-homepage`: 首页内容组织、作者简介和精选内容入口。
- `article-library`: 文章内容模型、列表、标签筛选、分页、详情及订阅输出。
- `personal-profile`: 关于页面与作者信息、外部链接展示。
- `article-search`: 面向已发布文章的站内搜索与结果反馈。
- `personal-notes`: 笔记内容模型、列表、详情和草稿发布规则。
- `site-experience`: 全站导航、响应式布局、主题偏好和基础可访问性与分享元信息。

### Modified Capabilities

无；项目目前没有主规格。

## Impact

- 新增博客前端工程、内容文件、站点配置、静态资源及构建流程；目前仓库没有应用代码可迁移。
- 需要静态站点框架、内容渲染与构建时搜索索引等依赖；无需数据库或后端服务。
- 部署时需配置作者资料、正式域名及真实文章；域名和托管平台在设计中保持可配置。
